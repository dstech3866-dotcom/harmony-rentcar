프로모션 이미지 자동 등록

홍보 이미지 한 장만 선택하면 홈페이지 최상단에 아반떼형 홍보 카드와 차량별 클릭 버튼을 자동 생성합니다. 블랙프라이데이 이미지에는 6개 차량 버튼이 자동 설정됩니다. 다른 이미지도 파일명에 있는 차종을 인식하여 버튼을 만듭니다. 인식되지 않은 차종은 기본 상품별 가격표 버튼으로 연결됩니다.

상세 설정 · 차량 버튼 직접 수정 (선택)

여러 프로모션 등록·관리

한 번 등록하면 별도 배포 없이 수정·표시·숨기기·삭제할 수 있습니다. 이미지 아래에 아반떼 프로모션처럼 여러 차종별 클릭 버튼을 만들 수 있습니다. 버튼 설정은 한 줄에 하나씩 입력하세요.

한 줄에 버튼명 | 상품 | 차종 | 연식 | 안내 문구 순서로 입력하세요. 상품은 신차렌트, 중고렌트, 신차리스, 중고리스, 6·12개월 중 하나입니다. 연식과 안내 문구는 생략 가능합니다.

홍보 이미지 색상 변경 · 업로드 공통 설정

원본 이미지는 보존됩니다. 파란색·하늘색 계열만 선택한 색상으로 변환합니다. 검정 글씨와 흰색 배경은 최대한 유지하지만 JPG의 색상 특성에 따라 일부 글씨에도 영향을 줄 수 있으므로 미리보기를 확인하세요.

카카오톡 링크 미리보기 대표 이미지 색상 변경

카카오톡 공유 시 나타나는 ‘신차·중고차 리스트 현황’ 이미지만 변경합니다. 기존 홍보 문구와 로고, 홈페이지 기능은 유지합니다.

이미지를 선택하지 않으면 현재 홈페이지의 카카오톡 대표 이미지를 사용합니다. 위쪽의 ‘색상 방식’에서 원본 유지 / 지정 색상 / 자동 변경을 선택하세요.

대표 이미지를 선택하지 않아도 현재 기본 이미지를 불러옵니다. 색상을 고르고 미리보기 후 「카카오톡 대표 이미지 게시」를 누르면 Supabase에 자동 저장됩니다. 첫 설치 시 Netlify 배포 및 Supabase 권한 설정이 필요합니다.

선택한 색상 방식은 일반 이미지, 블랙프라이데이, 통합 프로모션 이미지 업로드에 적용됩니다. 자동 변경은 업로드마다 색상을 무작위로 선택합니다.

관리자 로그인이 필요합니다.

※ 렌트 상품은 30개월 계약·리스 상품·비렌트 번호판을 제외합니다. 리스는 별도 분석하며 계약조건을 확인해 주세요. 미리보기 0대일 때는 게시할 수 없습니다. 게시한 목록은 다른 목록을 변경하지 않습니다.

차량 리스트 이미지 · 안내문 관리

4가지 상품별로 전체 상단·차종별 가격표 위·차량번호별 행에 이미지와 글을 각각 등록합니다. 엑셀 차량 정보는 변경되지 않습니다.

차종 또는 차량번호를 선택하거나 직접 입력하면 해당 위치에만 게시됩니다. 직접 입력 시 고객 가격표의 차종·차량번호와 정확히 일치해야 합니다.
