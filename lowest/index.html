가격표 파일로 미리보기 갱신

파트너즈에서 내려받은 XLS·XLSX 파일을 선택하세요. 업로드 파일은 이 브라우저에서 분석하며 서버에 자동 게시되지 않습니다. 관리자는 기존 메인 관리자 화면에서 각 상품을 게시할 수 있습니다.

실제 홈페이지에 최신 가격표를 반영하려면 메인 화면의 관리자 로그인 → 차량 리스트 관리 → 엑셀 미리보기 → 게시를 이용하세요. 이 페이지는 게시된 자료를 자동으로 다시 읽습니다.
